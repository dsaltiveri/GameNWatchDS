# Experiment archive

No historical experiments are currently archived in this project. Maintained
regressions belong in [tests/](../tests/README.md); development utilities belong
in [tools/](../tools/README.md).

Future studies should use descriptive topic/study folders, record their source
revision and evidence, and create annotated historical tags only when there is
a revision worth preserving. Generated or private evidence belongs under
`experiments/artifacts/`, which is ignored by Git.

See the [repository conventions](../docs/PROJECT_LAYOUT.md).
